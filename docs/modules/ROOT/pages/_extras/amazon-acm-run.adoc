ifndef::run-async[]
* Request a certificate with the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl "http://localhost:8080/sync?domainName=quarkus.local"
----

The endpoint returns the domain name of the certificate, `quarkus.local`.
endif::[]
ifdef::run-async[]
* Call the same endpoints with the asynchronous client, replacing `sync` with `async` in the URLs.
endif::[]
