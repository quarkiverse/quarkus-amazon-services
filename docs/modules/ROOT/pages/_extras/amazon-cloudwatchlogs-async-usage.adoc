:custom-async-usage:

Create a `org.acme.cloudwatchlogs.QuarkusCloudWatchLogsAsyncResource` REST resource that will be similar to our `QuarkusCloudWatchLogsSyncResource` but using an asynchronous programming model.

[source,java]
----
package org.acme.cloudwatchlogs;

import java.time.Instant;
import java.util.stream.Collectors;

import jakarta.inject.Inject;
import jakarta.ws.rs.FormParam;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.POST;
import jakarta.ws.rs.PUT;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

import io.smallrye.mutiny.Uni;
import software.amazon.awssdk.services.cloudwatchlogs.CloudWatchLogsAsyncClient;
import software.amazon.awssdk.services.cloudwatchlogs.model.OutputLogEvent;
import software.amazon.awssdk.services.cloudwatchlogs.model.ResourceAlreadyExistsException;

@Path("/async")
@Produces(MediaType.TEXT_PLAIN)
public class QuarkusCloudWatchLogsAsyncResource {

    @Inject
    CloudWatchLogsAsyncClient client;

    @POST
    public Uni<String> createLogStream(@FormParam("groupName") String groupName,
            @FormParam("streamName") String streamName) {
        return Uni.createFrom().completionStage(() -> client.createLogGroup(r -> r.logGroupName(groupName)))
                .replaceWithVoid()
                .onFailure(ResourceAlreadyExistsException.class).recoverWithNull()
                .chain(() -> Uni.createFrom().completionStage(
                        () -> client.createLogStream(r -> r.logGroupName(groupName).logStreamName(streamName))))
                .map(response -> "OK");
    }

    @PUT
    public Uni<String> putLogEvent(@FormParam("groupName") String groupName, @FormParam("streamName") String streamName,
            @FormParam("message") String message) {
        return Uni.createFrom().completionStage(client.putLogEvents(r -> r.logGroupName(groupName).logStreamName(streamName)
                .logEvents(e -> e.message(message).timestamp(Instant.now().toEpochMilli()))))
                .map(response -> "OK");
    }

    @GET
    public Uni<String> getLogEvents(@QueryParam("groupName") String groupName,
            @QueryParam("streamName") String streamName) {
        return Uni.createFrom().completionStage(
                client.getLogEvents(r -> r.logGroupName(groupName).logStreamName(streamName).startFromHead(true)))
                .map(response -> response.events().stream()
                        .map(OutputLogEvent::message)
                        .collect(Collectors.joining("\n")));
    }
}
----

Note that the `CloudWatchLogsAsyncClient` behaves just like the `CloudWatchLogsClient`, but returns `CompletionStage` objects which we use to create `Uni` instances.
The asynchronous client reports errors, such as `ResourceAlreadyExistsException`, as failures of the `Uni`, which we recover from to ignore an existing log group.
