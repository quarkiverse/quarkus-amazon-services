ifndef::run-async[]
* List the functions with the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl http://localhost:8080/sync
----

The endpoint returns `["quarkus-hello"]`.

* Get the runtime of the function:

[source,bash,subs="verbatim,attributes"]
----
curl http://localhost:8080/sync/quarkus-hello
----

The endpoint returns `nodejs22.x`.
endif::[]
ifdef::run-async[]
* Call the same endpoints with the asynchronous client, replacing `sync` with `async` in the URLs.
endif::[]
