ifndef::run-async[]
* Create a REST API with the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl -X POST "http://localhost:8080/sync?name=quarkus-api"
----

The endpoint returns the ID of the REST API.

* Get the REST API, replacing `<id>` with the returned ID:

[source,bash,subs="verbatim,attributes"]
----
curl http://localhost:8080/sync/<id>
----

The endpoint returns `quarkus-api`.
endif::[]
ifdef::run-async[]
* Call the same endpoints with the asynchronous client, replacing `sync` with `async` in the URLs.
endif::[]
