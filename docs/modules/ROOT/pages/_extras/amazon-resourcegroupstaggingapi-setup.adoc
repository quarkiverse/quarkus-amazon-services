=== Create a resource to tag

The Resource Groups Tagging API manages the tags of resources created by other AWS services.
Create a SQS queue with the AWS CLI of the Floci container, and store its ARN, which you will pass to the application:

[source,bash,subs="verbatim,attributes"]
----
queue_url=$(docker exec floci aws sqs create-queue --queue-name quarkus-tagging --query QueueUrl --output text)
export RESOURCE_ARN=$(docker exec floci aws sqs get-queue-attributes --queue-url $queue_url --attribute-names QueueArn --query Attributes.QueueArn --output text)
----

=== Set up a resource on your AWS account

If you want to use your AWS account, create the same queue with your own AWS CLI:

[source,bash,subs="verbatim,attributes"]
----
queue_url=$(aws sqs create-queue --queue-name quarkus-tagging --query QueueUrl --output text)
export RESOURCE_ARN=$(aws sqs get-queue-attributes --queue-url $queue_url --attribute-names QueueArn --query Attributes.QueueArn --output text)
----

Any taggable resource works: you can use the ARN of an existing resource of your account instead.
