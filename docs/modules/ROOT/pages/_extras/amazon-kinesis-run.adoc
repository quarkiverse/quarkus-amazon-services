ifndef::run-async[]
* Create a stream with the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl -X POST "http://localhost:8080/sync?name=quarkus-stream"
----

* Get the status of the stream:

[source,bash,subs="verbatim,attributes"]
----
curl http://localhost:8080/sync/quarkus-stream
----

The endpoint returns `ACTIVE` once the stream is ready.
endif::[]
ifdef::run-async[]
* Call the same endpoints with the asynchronous client, replacing `sync` with `async` in the URLs.
endif::[]
