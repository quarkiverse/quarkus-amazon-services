ifndef::run-async[]
* Open a browser to `http://localhost:8080/s3.html` to use the synchronous client
* Upload new files to the current S3 bucket via the form and see the list of files in the bucket
endif::[]
ifdef::run-async[]
* Open a browser to `http://localhost:8080/async-s3.html` to use the asynchronous client
endif::[]
