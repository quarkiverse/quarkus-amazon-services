=== Create a SQS queue

Create the queue used by the application with the AWS CLI of the Floci container:

[source,bash,subs="verbatim,attributes"]
----
docker exec floci aws sqs create-queue --queue-name=Quarkus
----

=== Set up SQS on your AWS account

If you want to use your SQS queue on your AWS account, create it with your own AWS CLI and store its URL, which you will pass to the application:

[source,bash,subs="verbatim,attributes"]
----
export QUEUE_URL=$(aws sqs create-queue --queue-name=Quarkus --query QueueUrl --output text)
----
