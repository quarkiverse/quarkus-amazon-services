== Creating JSON REST service

In this example, we will create an application that creates a log group and a log stream, pushes log events to the stream and reads them back using a RESTful API.
The example application will demonstrate the two programming models supported by the extension.

Let's start with the synchronous implementation in the `org.acme.cloudwatchlogs.QuarkusCloudWatchLogsSyncResource` class.

[source,java]
----
package org.acme.cloudwatchlogs;

import java.time.Instant;
import java.util.stream.Collectors;

import jakarta.inject.Inject;
import jakarta.ws.rs.FormParam;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.POST;
import jakarta.ws.rs.PUT;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

import software.amazon.awssdk.services.cloudwatchlogs.CloudWatchLogsClient;
import software.amazon.awssdk.services.cloudwatchlogs.model.OutputLogEvent;
import software.amazon.awssdk.services.cloudwatchlogs.model.ResourceAlreadyExistsException;

@Path("/sync")
@Produces(MediaType.TEXT_PLAIN)
public class QuarkusCloudWatchLogsSyncResource {

    @Inject <1>
    CloudWatchLogsClient client;

    @POST
    public String createLogStream(@FormParam("groupName") String groupName, @FormParam("streamName") String streamName) {
        try {
            client.createLogGroup(r -> r.logGroupName(groupName)); <2>
        } catch (ResourceAlreadyExistsException e) {
            // The log group already exists
        }
        client.createLogStream(r -> r.logGroupName(groupName).logStreamName(streamName)); <3>
        return "OK";
    }

    @PUT
    public String putLogEvent(@FormParam("groupName") String groupName, @FormParam("streamName") String streamName,
            @FormParam("message") String message) {
        client.putLogEvents(r -> r.logGroupName(groupName).logStreamName(streamName) <4>
                .logEvents(e -> e.message(message).timestamp(Instant.now().toEpochMilli())));
        return "OK";
    }

    @GET
    public String getLogEvents(@QueryParam("groupName") String groupName, @QueryParam("streamName") String streamName) {
        return client.getLogEvents(r -> r.logGroupName(groupName).logStreamName(streamName).startFromHead(true)) <5>
                .events()
                .stream()
                .map(OutputLogEvent::message)
                .collect(Collectors.joining("\n"));
    }
}
----

<1> Inject the client provided by the amazon-cloudwatchlogs extension
<2> Create the log group, unless it already exists
<3> Create the log stream in the log group
<4> Push a log event to the log stream
<5> Read the log events of the stream, oldest first
