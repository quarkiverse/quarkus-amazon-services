ifndef::run-async[]
* Store a secret named `quarkus-password` with the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl -X PUT -H "Content-Type: text/plain" -d "Quarkus is awesome" http://localhost:8080/sync/quarkus-password
----

The endpoint returns the ARN of the secret.

* Retrieve the secret:

[source,bash,subs="verbatim,attributes"]
----
curl http://localhost:8080/sync/quarkus-password
----

The endpoint returns `Quarkus is awesome`.
endif::[]
ifdef::run-async[]
* Call the same endpoints with the asynchronous client, replacing `sync` with `async` in the URLs. Use another secret name, as the secret `quarkus-password` already exists.
endif::[]
