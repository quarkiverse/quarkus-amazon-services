:custom-async-usage:

Create a `org.acme.cloudwatch.QuarkusCloudWatchAsyncResource` REST resource that will be similar to our `QuarkusCloudWatchSyncResource` but using an asynchronous programming model.

[source,java]
----
package org.acme.cloudwatch;

import java.time.Instant;
import java.util.LinkedHashSet;
import java.util.Set;

import jakarta.inject.Inject;
import jakarta.ws.rs.FormParam;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.PUT;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

import io.smallrye.mutiny.Uni;
import software.amazon.awssdk.services.cloudwatch.CloudWatchAsyncClient;
import software.amazon.awssdk.services.cloudwatch.model.StandardUnit;

@Path("/async")
@Produces(MediaType.TEXT_PLAIN)
public class QuarkusCloudWatchAsyncResource {

    @Inject
    CloudWatchAsyncClient client;

    @PUT
    public Uni<String> putMetricData(@FormParam("namespace") String namespace, @FormParam("name") String name) {
        return Uni.createFrom().completionStage(client.putMetricData(r -> r.namespace(namespace)
                .metricData(d -> d.metricName(name)
                        .timestamp(Instant.now())
                        .value(1.0)
                        .unit(StandardUnit.COUNT))))
                .map(response -> "OK");
    }

    @GET
    public Uni<String> listMetrics(@QueryParam("namespace") String namespace) {
        Set<String> names = new LinkedHashSet<>();
        return Uni.createFrom().completionStage(client.listMetricsPaginator(r -> r.namespace(namespace))
                .metrics()
                .subscribe(metric -> names.add(metric.metricName())))
                .map(ignored -> String.join(", ", names));
    }
}
----

Note that the `CloudWatchAsyncClient` behaves just like the `CloudWatchClient`, but returns `CompletionStage` objects which we use to create `Uni` instances.
The asynchronous paginator emits the metrics of all the pages to the consumer passed to `subscribe`, and completes the returned `CompletableFuture` after the last page.
