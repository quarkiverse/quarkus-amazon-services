== Creating JSON REST service

In this example, we will create an application that pushes data points to a metric and lists the metrics of a namespace using a RESTful API.
The example application will demonstrate the two programming models supported by the extension.

Let's start with the synchronous implementation in the `org.acme.cloudwatch.QuarkusCloudWatchSyncResource` class.

[source,java]
----
package org.acme.cloudwatch;

import java.time.Instant;
import java.util.stream.Collectors;

import jakarta.inject.Inject;
import jakarta.ws.rs.FormParam;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.PUT;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

import software.amazon.awssdk.services.cloudwatch.CloudWatchClient;
import software.amazon.awssdk.services.cloudwatch.model.Metric;
import software.amazon.awssdk.services.cloudwatch.model.StandardUnit;

@Path("/sync")
@Produces(MediaType.TEXT_PLAIN)
public class QuarkusCloudWatchSyncResource {

    @Inject <1>
    CloudWatchClient client;

    @PUT
    public String putMetricData(@FormParam("namespace") String namespace, @FormParam("name") String name) {
        client.putMetricData(r -> r.namespace(namespace) <2>
                .metricData(d -> d.metricName(name)
                        .timestamp(Instant.now())
                        .value(1.0)
                        .unit(StandardUnit.COUNT)));
        return "OK";
    }

    @GET
    public String listMetrics(@QueryParam("namespace") String namespace) {
        return client.listMetricsPaginator(r -> r.namespace(namespace)) <3>
                .metrics()
                .stream()
                .map(Metric::metricName)
                .distinct()
                .collect(Collectors.joining(", "));
    }
}
----

<1> Inject the client provided by the amazon-cloudwatch extension
<2> Push a data point with a value of `1` to the metric
<3> List the metrics of the namespace, fetching all the pages of results
