:custom-async-usage:

Create a `org.acme.secretsmanager.QuarkusSecretsManagerAsyncResource` REST resource that will be similar to our `QuarkusSecretsManagerSyncResource` but using an asynchronous programming model.

[source,java]
----
package org.acme.secretsmanager;

import jakarta.inject.Inject;
import jakarta.ws.rs.Consumes;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.PUT;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.PathParam;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.core.MediaType;

import io.smallrye.mutiny.Uni;
import software.amazon.awssdk.services.secretsmanager.SecretsManagerAsyncClient;

@Path("/async")
public class QuarkusSecretsManagerAsyncResource {

    @Inject
    SecretsManagerAsyncClient secretsManagerAsyncClient;

    @PUT
    @Path("/{name}")
    @Consumes(MediaType.TEXT_PLAIN)
    @Produces(MediaType.TEXT_PLAIN)
    public Uni<String> createSecret(@PathParam("name") String name, String value) {
        return Uni.createFrom().completionStage(secretsManagerAsyncClient.createSecret(r -> r.name(name).secretString(value)))
                .map(response -> response.arn());
    }

    @GET
    @Path("/{name}")
    @Produces(MediaType.TEXT_PLAIN)
    public Uni<String> getSecret(@PathParam("name") String name) {
        return Uni.createFrom().completionStage(secretsManagerAsyncClient.getSecretValue(r -> r.secretId(name)))
                .map(response -> response.secretString());
    }
}
----

Note that the `SecretsManagerAsyncClient` behaves just like the `SecretsManagerClient`, but returns `CompletionStage` objects which we use to create `Uni` instances, and then transform the emitted item.
