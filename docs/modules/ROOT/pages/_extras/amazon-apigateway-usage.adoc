== Creating JSON REST service

In this example, we will create an application that creates REST APIs in API Gateway and reads them back using a RESTful API.
The example application will demonstrate the two programming models supported by the extension.

Let's start with the synchronous implementation in the `org.acme.apigateway.QuarkusApiGatewaySyncResource` class.

[source,java]
----
package org.acme.apigateway;

import jakarta.inject.Inject;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.POST;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.PathParam;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

import software.amazon.awssdk.services.apigateway.ApiGatewayClient;

@Path("/sync")
@Produces(MediaType.TEXT_PLAIN)
public class QuarkusApiGatewaySyncResource {

    @Inject <1>
    ApiGatewayClient apiGateway;

    @POST
    public String createRestApi(@QueryParam("name") String name) {
        return apiGateway.createRestApi(r -> r.name(name)).id(); <2>
    }

    @GET
    @Path("/{id}")
    public String getRestApi(@PathParam("id") String id) {
        return apiGateway.getRestApi(r -> r.restApiId(id)).name(); <3>
    }
}
----

<1> Inject the client provided by the amazon-apigateway extension
<2> Create a REST API and return its ID
<3> Get the REST API and return its name
