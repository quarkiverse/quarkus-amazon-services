=== Create the target queue

The schedules of this guide send a message to an SQS queue.
Create the `quarkus-schedules` queue, using the AWS CLI of the Floci container:

[source,bash,subs="verbatim,attributes"]
----
docker exec floci aws sqs create-queue --queue-name quarkus-schedules
----

=== Set up the target on your AWS account

If you want to use your AWS account, create the queue with your own AWS CLI, and an IAM role that EventBridge Scheduler can assume to send messages to the queue, as described in https://docs.aws.amazon.com/scheduler/latest/UserGuide/setting-up.html#setting-up-execution-role[Set up the execution role].
Then use the ARNs of the queue and of the role in the configuration of the application.
