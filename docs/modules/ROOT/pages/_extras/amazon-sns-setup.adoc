=== Create a SNS topic

Create a SNS topic using the AWS CLI of the Floci container and store its ARN in the `TOPIC_ARN` environment variable:

[source,bash,subs="verbatim,attributes"]
----
export TOPIC_ARN=$(docker exec floci aws sns create-topic --name=QuarksCollider --query TopicArn --output text)
----

[WARNING]
====
If you are using Floci, the notifications are sent from the Floci container, so it must be able to reach your application:

- Set the `quarks.shield.base.url` configuration property in your `application.properties` to an address of your host that is reachable from the container, for example `http://host.docker.internal:${quarkus.http.port}`.
On Linux, `host.docker.internal` is only resolvable if the container is started with `--add-host=host.docker.internal:host-gateway`:

[source,bash,subs="verbatim,attributes"]
----
docker run --rm --name floci --publish 4566:4566 --add-host=host.docker.internal:host-gateway -d floci/floci:latest-compat
----

- Set the `quarkus.http.host` configuration property in your `application.properties` to `0.0.0.0`.
Be aware that Quarkus will then listen to all interfaces, which might be a security hazard depending on your network configuration.

Otherwise your service will not receive the notifications.
====

=== Set up SNS on your AWS account

If you want to run the demo using SNS on your AWS account, create a topic using your default profile:

[source,bash,subs="verbatim,attributes"]
----
export TOPIC_ARN=$(aws sns create-topic --name=QuarksCollider --query TopicArn --output text)
----
