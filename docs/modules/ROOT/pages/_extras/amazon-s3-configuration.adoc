In both cases, set the name of the S3 bucket used by the application:

[source,properties]
----
bucket.name=quarkus.s3.quickstart
----

When using Dev Services, you can also let it create the bucket on startup:

[source,properties]
----
quarkus.s3.devservices.buckets=${bucket.name}
----

For the asynchronous client, refer to <<Going asynchronous>> for more information.
