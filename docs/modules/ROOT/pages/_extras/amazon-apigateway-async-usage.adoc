:custom-async-usage:

Create a `org.acme.apigateway.QuarkusApiGatewayAsyncResource` REST resource that will be similar to our `QuarkusApiGatewaySyncResource` but using an asynchronous programming model.

[source,java]
----
package org.acme.apigateway;

import jakarta.inject.Inject;
import jakarta.ws.rs.GET;
import jakarta.ws.rs.POST;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.PathParam;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

import io.smallrye.mutiny.Uni;
import software.amazon.awssdk.services.apigateway.ApiGatewayAsyncClient;

@Path("/async")
@Produces(MediaType.TEXT_PLAIN)
public class QuarkusApiGatewayAsyncResource {

    @Inject
    ApiGatewayAsyncClient apiGateway;

    @POST
    public Uni<String> createRestApi(@QueryParam("name") String name) {
        return Uni.createFrom().completionStage(apiGateway.createRestApi(r -> r.name(name)))
                .map(response -> response.id());
    }

    @GET
    @Path("/{id}")
    public Uni<String> getRestApi(@PathParam("id") String id) {
        return Uni.createFrom().completionStage(apiGateway.getRestApi(r -> r.restApiId(id)))
                .map(response -> response.name());
    }
}
----

Note that the `ApiGatewayAsyncClient` behaves just like the `ApiGatewayClient`, but returns `CompletionStage` objects which we use to create `Uni` instances, and then transform the emitted item.
