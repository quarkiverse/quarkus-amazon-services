== Verify the sender address with Dev Services

Floci rejects a send request when the sender address is not verified, but it does not require the recipient to be verified, and it does not send any email.
Let Dev Services verify the sender address when it starts the container it owns:

[source,properties]
----
quarkus.ses.devservices.verified-emails=from-quarkus@example.com
----

The property takes a comma-separated list of email addresses, and Dev Services verifies each of them on the local stack, so an init script is not needed.
These identities only exist in the local stack: no email is sent, and no address has to be confirmed.

The property is optional, and Dev Services verifies no address when it is not set.
The sender then has to be verified with the AWS CLI, as shown when you provision the local stack manually.
