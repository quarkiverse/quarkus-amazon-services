* Prompt the model with the `Converse` API and the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl -XPOST -H"Content-type: text/plain" http://localhost:8080/sync/converse -d'What is Quarkus?'
----

Floci does not run the model and returns a canned answer:

[source,text]
----
Floci stub response for model=anthropic.claude-3-haiku-20240307-v1:0
----

* Prompt the model with the `InvokeModel` API:

[source,bash,subs="verbatim,attributes"]
----
curl -XPOST -H"Content-type: text/plain" http://localhost:8080/sync/invoke -d'What is Quarkus?'
----

You should see output like this:

[source,text]
----
Floci stub response
----

* Replace `sync` with `async` to use the asynchronous client.
* Stream the answer with the `ConverseStream` API, only available with the asynchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl -XPOST -H"Content-type: text/plain" http://localhost:8080/async/converse-stream -d'What is Quarkus?'
----

You should see output like this:

[source,text]
----
Floci stub response for model=anthropic.claude-3-haiku-20240307-v1:0
----

On AWS, these endpoints return the answer generated by the model.
