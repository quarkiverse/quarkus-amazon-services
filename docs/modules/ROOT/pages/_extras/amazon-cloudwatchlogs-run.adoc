ifndef::run-async[]
* Create the `quarkus` log group and its `app` log stream with the synchronous client:

[source,bash,subs="verbatim,attributes"]
----
curl -X POST -d groupName=quarkus -d streamName=app http://localhost:8080/sync
----

* Push a log event to the stream:

[source,bash,subs="verbatim,attributes"]
----
curl -X PUT -d groupName=quarkus -d streamName=app -d "message=Quarkus is awesome" http://localhost:8080/sync
----

* Read the log events of the stream:

[source,bash,subs="verbatim,attributes"]
----
curl "http://localhost:8080/sync?groupName=quarkus&streamName=app"
----

The endpoint returns `Quarkus is awesome`.
endif::[]
ifdef::run-async[]
* Call the same endpoints with the asynchronous client, replacing `sync` with `async` in the URLs. Use another stream name, as the stream `app` already exists.
endif::[]
