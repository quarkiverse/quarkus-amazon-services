AWS Marketplace Entitlement Service is an API that AWS Marketplace sellers use to check what their customers are entitled to, for example for SaaS contract or container products.
This client retrieves the entitlement values of a product, which you can filter by customer identifier, customer AWS account ID, license ARN or dimension.
