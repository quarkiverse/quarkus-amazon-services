Elastic Load Balancing automatically distributes incoming traffic across multiple targets, such as EC2 instances, containers and IP addresses, in one or more Availability Zones.
This client uses the Elastic Load Balancing API version 2015-12-01 to manage Application Load Balancers, Network Load Balancers and Gateway Load Balancers, with their listeners, rules and target groups.
To manage Classic Load Balancers, use the Elastic Load Balancing extension.
