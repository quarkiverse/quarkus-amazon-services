:solution-summary: The application built here tags AWS resources, finds them by tag and removes their tags.
:aws-docs-url: https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/

The AWS Resource Groups Tagging API lets you manage the tags of resources across many AWS services from a single place.
This client lets you tag and untag resources in bulk, find resources by tag, list the tag keys and values in use, and report on tag policy compliance.
