:solution-summary: The application built here creates a log group and a log stream, pushes log events to the stream and reads them back.
:aws-docs-url: https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/WhatIsCloudWatchLogs.html

Amazon CloudWatch Logs lets you centralize, monitor, store and access the log files of your systems, applications and AWS services, such as Amazon EC2, AWS CloudTrail and Route 53.
This client lets you manage log groups and log streams, put and retrieve log events, and query logs.
