:solution-summary: The application built here creates Step Functions state machines and lists them.
:aws-docs-url: https://docs.aws.amazon.com/step-functions/latest/dg/welcome.html

AWS Step Functions is a serverless orchestration service that lets you coordinate AWS services, such as AWS Lambda, Amazon DynamoDB and Amazon SQS, into workflows defined as state machines.
This client lets you create and manage state machines, and start, stop and inspect their executions.
