AWS Transfer Family is a fully managed service for transferring files into and out of Amazon S3 and Amazon EFS over SFTP, FTPS, FTP and AS2, and through browser-based web apps.
This client lets you manage servers, users, connectors, AS2 profiles and agreements, web apps and managed workflows.
