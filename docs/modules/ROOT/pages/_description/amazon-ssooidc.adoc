AWS IAM Identity Center OpenID Connect (OIDC) is a web service that lets a client, such as the AWS CLI or a native application, register with IAM Identity Center and get the access token of a user after the user signs in.
The token is then used with the IAM Identity Center portal API, available in the AWS IAM Identity Center extension, to get AWS credentials.
