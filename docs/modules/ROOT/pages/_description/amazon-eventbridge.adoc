:solution-summary: The application built here creates scheduled EventBridge rules and describes them.

Amazon EventBridge is a serverless event bus service that connects your applications with data from a variety of sources.
This client lets you manage event buses and rules, put custom events, and configure targets, archives and replays, connections and API destinations.
