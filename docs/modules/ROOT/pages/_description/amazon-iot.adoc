AWS IoT Core lets you securely connect IoT devices to the AWS Cloud and to other devices.
This client uses the AWS IoT control plane API to manage things, thing types and groups, certificates and policies, rules and jobs.
Publishing messages and accessing device shadows use the separate AWS IoT data plane API.
