Amazon Bedrock is a fully managed service that provides access to high-performing foundation models from leading AI companies.
This client uses the Amazon Bedrock Runtime API to run inference on these models, for example with the Converse and InvokeModel operations, including streaming responses.
To manage models, guardrails and customization jobs, use the Amazon Bedrock extension.
