Amazon Simple Email Service (Amazon SES) is a cloud email service for sending and receiving email.
This client uses the original SES API (v1), which you still need to manage email receiving, with receipt rules and filters.
For sending, AWS recommends the SES API v2, available in the Amazon SES API v2 extension, as new sending features are only added there.
