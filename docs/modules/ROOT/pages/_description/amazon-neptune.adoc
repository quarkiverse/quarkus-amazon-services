Amazon Neptune is a fully managed graph database service for building applications that work with highly connected datasets.
This client uses the Neptune management API to create and manage DB clusters, instances, parameter groups, snapshots and global databases.
To load data or run Gremlin or openCypher queries, use the https://docs.aws.amazon.com/neptune/latest/data-api/Welcome.html[Neptune data API] instead.
