:solution-summary: The application built here assumes an IAM role to get temporary credentials.
:aws-docs-url: https://docs.aws.amazon.com/STS/latest/APIReference/

AWS Security Token Service (AWS STS) is a web service that issues temporary, limited-privilege credentials.
This client lets you assume IAM roles, including with SAML or web identity federation, get session and federation tokens, and get the identity of the caller.
