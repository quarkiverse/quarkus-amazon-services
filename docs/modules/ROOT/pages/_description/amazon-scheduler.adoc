Amazon EventBridge Scheduler is a serverless scheduler that lets you create, run and manage scheduled tasks at scale, invoking more than 270 AWS services.
This client lets you manage schedules and schedule groups using cron, rate or one-time expressions, with flexible time windows and retry policies.
