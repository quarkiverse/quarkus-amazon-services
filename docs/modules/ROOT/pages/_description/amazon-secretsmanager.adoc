:solution-summary: The application built here stores secrets in Secrets Manager and retrieves them.
:aws-docs-url: https://docs.aws.amazon.com/secretsmanager/latest/userguide/intro.html

AWS Secrets Manager helps you store, manage, rotate and retrieve database credentials, API keys and other secrets, so that they are not hardcoded in your application.
This client lets you create, update and retrieve secrets and configure their rotation.
