:solution-summary: The application built here creates Kinesis data streams and gets their status.
:aws-docs-url: https://docs.aws.amazon.com/streams/latest/dev/introduction.html

Amazon Kinesis Data Streams is a serverless streaming data service for capturing, processing and storing data streams in real time at any scale.
This client lets you create and manage streams and shards, write records to them and read records from them.
