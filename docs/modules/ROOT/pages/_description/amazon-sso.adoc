AWS IAM Identity Center, the successor to AWS Single Sign-On, is the recommended service for managing the access of your workforce to multiple AWS accounts and applications.
This client uses the IAM Identity Center portal API: with the access token of a user, it lists the AWS accounts and roles assigned to the user, gets short-term credentials for a role and signs the user out.
To get the access token of a user, use the AWS IAM Identity Center OIDC extension.
