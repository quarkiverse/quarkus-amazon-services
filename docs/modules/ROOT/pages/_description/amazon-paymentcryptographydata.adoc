AWS Payment Cryptography is a managed service for the cryptographic operations used in payment processing.
This client uses the data plane API to encrypt, decrypt and re-encrypt payment data, and to generate, verify and translate PINs, card data and MACs, with your keys.
To manage the keys, use the AWS Payment Cryptography extension.
