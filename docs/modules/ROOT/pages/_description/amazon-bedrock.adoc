:solution-summary: The application built here manages Amazon Bedrock guardrails.
:aws-docs-url: https://docs.aws.amazon.com/bedrock/latest/userguide/what-is-bedrock.html

Amazon Bedrock is a fully managed service that provides access to high-performing foundation models from leading AI companies, to build and scale generative AI applications.
This client uses the Amazon Bedrock control plane API to manage models and related resources, such as model customization jobs, provisioned throughput, model evaluation jobs and guardrails.
To run inference, use the Amazon Bedrock Runtime extension.
