Amazon Cognito user pools are user directories that provide sign-up, sign-in and token-based authentication to your web and mobile applications.
This client uses the Amazon Cognito user pools API (Cognito Identity Provider) to create and manage user pools, app clients and users, and to authenticate users to get identity, access and refresh tokens.
