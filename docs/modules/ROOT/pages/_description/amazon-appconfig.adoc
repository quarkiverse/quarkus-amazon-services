AWS AppConfig helps you safely change the behavior of your application in production without deploying new code, using feature flags and dynamic free-form configurations.
This client uses the AWS AppConfig control plane API to create and manage applications, environments, configuration profiles, validators and deployment strategies, and to start and monitor deployments.
To retrieve configuration data at runtime, use the AWS AppConfig Data extension.
