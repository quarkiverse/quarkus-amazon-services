AWS Cost Explorer lets you view and analyze your AWS costs and usage, with up to 13 months of historical data and forecasts for the next 18 months.
This client uses the Cost Explorer API to query cost and usage data, get cost forecasts, and get Reserved Instances and Savings Plans recommendations and utilization.
Each paginated API request is charged.
